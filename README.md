# 文字起こしアプリ

録音ファイルをブラウザから Gemini API（無料枠）に送り、文字起こし・整文・要約・決定事項/ToDo の抽出を行う、単一HTMLファイルのWebアプリです。

公開ページ: https://iidodo-com.github.io/mojiokoshi/

## 使い方

1. ページを開く
2. 「設定」に Gemini APIキーを入力して「設定を保存」を押す
   - キーの取得: [Google AI Studio](https://aistudio.google.com/apikey) でGoogleアカウントを使って発行
   - キーは使っているブラウザ内にのみ保存され、コードやリポジトリには含まれません
3. 音声ファイル（m4a / mp3 / wav / aac / ogg / flac など）を選ぶ
4. 欲しい出力（整文・要約・決定事項/ToDo）にチェックを入れて「文字起こしを実行」
5. 結果はコピー、または .md / .txt で保存できます

## 仕様と制限

- サーバーを持たない静的ページです。音声はブラウザから Gemini API へ直接送信されます
- 15MB以下のファイルはそのまま送信、大きいファイルは Gemini の Files API 経由でアップロードします
- 長い音声は数十分までが目安です。無料枠の上限（1日あたりの回数など）はGoogle側の条件によります
- モデル名は設定で変更できます（既定: gemini-3.8-flash）
